Features

Everything a real voice AI platform needs

Designed to mirror commercial voice-agent products, end to end.

Multilingual Understanding

Automatic spoken-language detection across 12+ languages with real-time transcription via the Web Speech API.

Retrieval-Augmented Generation

Upload PDFs, DOCX, or TXT files. Content is chunked, embedded, and stored in Pinecone for grounded, accurate answers.

Contextual AI Responses

Gemini LLM combines retrieved knowledge with conversation history to generate natural, on-topic replies.

Natural Voice Synthesis

Responses are spoken back instantly using the browser SpeechSynthesis API, matched to the detected language.

Real-Time Analytics

Track call volume, sentiment trends, language distribution, and latency with live Chart.js dashboards.

Full Call Logging

Every conversation is transcribed, summarized, and stored in SQLite with searchable filters and full transcripts.

How It Works

From spoken words to grounded answers

The full RAG + voice pipeline, visualized.

1. Capture Speech

User speaks; browser captures audio via Web Speech API.

2. Detect Language

Spoken language identified and transcribed to text.

3. Embed & Search

Query embedded and matched against Pinecone vector index.

4. Generate Response

Top chunks + context sent to Gemini LLM for a grounded reply.

5. Speak Reply

Response synthesized to speech and played back to the user.
